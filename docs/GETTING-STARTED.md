# Getting Started Guide

**Welcome to the OPT Plus Digital System development team!** 🎉

This guide will get you up and running in under 30 minutes.

## Prerequisites Checklist

Before you begin, ensure you have:

- [ ] **PHP 8.3+** installed (`php -v` to check)
- [ ] **Composer 2.x** installed (`composer -V` to check)
- [ ] **Node.js 20+** installed (`node -v` to check)
- [ ] **Git** installed (`git --version` to check)
- [ ] **MySQL 8.0+** or SQLite (for development)
- [ ] A code editor (VS Code recommended)

### Installing Prerequisites

#### Windows (via Scoop)
```powershell
# Install Scoop
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
irm get.scoop.sh | iex

# Install PHP, Composer, Node.js
scoop install php composer nodejs-lts mysql

# Or use Laravel Herd (includes PHP, Composer, MySQL)
# Download from: https://herd.laravel.com/windows
```

#### macOS (via Homebrew)
```bash
# Install Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install PHP, Composer, Node.js
brew install php composer node mysql

# Or use Laravel Herd
# Download from: https://herd.laravel.com
```

#### Ubuntu/Debian
```bash
# PHP 8.3
sudo add-apt-repository ppa:ondrej/php
sudo apt update
sudo apt install php8.3 php8.3-{cli,fpm,mysql,mbstring,xml,curl,zip,gd}

# Composer
php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"
php composer-setup.php --install-dir=/usr/local/bin --filename=composer

# Node.js 20
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install nodejs

# MySQL
sudo apt install mysql-server
```

## Quick Start (5 minutes)

### 1. Clone the Repository

```bash
git clone https://github.com/your-org/opt-plus-digital.git
cd opt-plus-digital
```

### 2. Run Automated Setup

```bash
composer setup
```

This single command will:
- ✅ Install PHP dependencies
- ✅ Copy `.env.example` to `.env`
- ✅ Generate application key
- ✅ Run database migrations
- ✅ Install Node.js dependencies
- ✅ Build frontend assets

### 3. Configure Database

**Option A: SQLite (Easiest for development)**

Already configured! The `database.sqlite` file was created during setup.

**Option B: MySQL**

1. Create a database:
```bash
mysql -u root -p
CREATE DATABASE optplus;
EXIT;
```

2. Update `.env`:
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=optplus
DB_USERNAME=root
DB_PASSWORD=your_password
```

3. Run migrations:
```bash
php artisan migrate
```

### 4. Start Development Servers

```bash
composer dev
```

This starts:
- 🚀 Laravel server at `http://localhost:8000`
- 🔄 Queue worker for background jobs
- ⚡ Vite dev server with Hot Module Replacement

### 5. Open in Browser

Visit: **http://localhost:8000**

You should see the OPT Plus welcome page! 🎉

### 6. Create Your First Account

Click "Register" and create an account. The first user will be an admin.

## Development Workflow

### Creating a New Feature

1. **Create a branch**
```bash
git checkout -b feature/child-registration
```

2. **Create backend components**
```bash
# Controller
php artisan make:controller ChildController

# Model + Migration
php artisan make:model Child -mf
```

3. **Write migration**
```php
// database/migrations/xxxx_create_children_table.php
Schema::create('children', function (Blueprint $table) {
    $table->uuid('id')->primary();
    $table->string('first_name');
    // ... more fields
});
```

4. **Run migration**
```bash
php artisan migrate
```

5. **Create frontend component**
```tsx
// resources/js/pages/Children/Index.tsx
export default function Index({ children }) {
  return <div>Children list here</div>;
}
```

6. **Add route**
```php
// routes/web.php
Route::get('/children', [ChildController::class, 'index'])
    ->name('children.index');
```

7. **Regenerate type-safe routes**
```bash
php artisan wayfinder:generate
```

8. **Test your changes**
```bash
composer test
```

9. **Commit and push**
```bash
git add .
git commit -m "feat: add child registration module"
git push origin feature/child-registration
```

## Troubleshooting

### Issue: "composer: command not found"
**Solution:** Install Composer globally
```bash
# Download installer
php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"

# Install globally
php composer-setup.php --install-dir=/usr/local/bin --filename=composer

# Verify
composer -V
```

### Issue: "npm: command not found"
**Solution:** Install Node.js
```bash
# macOS
brew install node

# Ubuntu
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install nodejs
```

### Issue: "SQLSTATE[HY000] [2002] Connection refused"
**Solution:** Start MySQL
```bash
# macOS
brew services start mysql

# Ubuntu
sudo service mysql start

# Windows (via XAMPP/WAMP)
# Start MySQL from control panel
```

### Issue: Vite not connecting (HMR not working)
**Solution:** Check APP_URL in .env
```env
APP_URL=http://localhost:8000
```
Then restart dev servers:
```bash
# Stop with Ctrl+C, then restart
composer dev
```

### Issue: "Class not found"
**Solution:** Regenerate autoload
```bash
composer dump-autoload
```

### Issue: Route not found (404)
**Solution:** Clear route cache
```bash
php artisan route:clear
php artisan wayfinder:generate
```
